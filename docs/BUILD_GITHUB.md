# بناء Lisancom عبر GitHub وتثبيته

## 1) رفع المشروع (مرة واحدة)
1. أنشئ حسابًا على github.com، ثم ثبّت **GitHub Desktop** (desktop.github.com) وسجّل الدخول.
2. فك ضغط `lisancom-v0.2.zip`.
3. GitHub Desktop ← File ← **Add local repository** ← اختر مجلد `lisancom`
   ← سيقول إنه ليس مستودعًا ← اضغط **create a repository** ← Create.
4. اضغط **Publish repository** (يمكن جعله Private).
5. افتح المستودع على github.com ← تبويب **Actions** ← سيبدأ «Build Lisancom» تلقائيًا (Android نحو 10 دقائق، iOS نحو 15–25 دقيقة).

## 2) تنزيل الملفات
Actions ← آخر تشغيل (علامة ✓ خضراء) ← أسفل الصفحة **Artifacts**:
- `Lisancom-Android-APK` ← zip بداخله `app-release.apk`.
- `Lisancom-iOS-IPA` ← zip بداخله `Lisancom.ipa`.
إذا فشل التشغيل (✗ أحمر): افتحه ← اضغط الخطوة الحمراء ← انسخ آخر الأسطر وأرسلها.

> المستودع الخاص: الخطة المجانية تمنح دقائق محدودة شهريًا، ودقائق macOS تُحسب بأضعاف. المستودع العام بلا حد للدقائق.
> لإعادة البناء يدويًا: Actions ← Build Lisancom ← **Run workflow**.

## 3) أندرويد
انسخ `app-release.apk` إلى الجوال ← افتحه من «الملفات» ← اسمح بتثبيت تطبيقات غير معروفة ← تثبيت.

## 4) الآيفون عبر Sideloadly (Windows)
1. ثبّت **iTunes** و**iCloud** من موقع Apple مباشرة (ليس من Microsoft Store)، ثم **Sideloadly** من sideloadly.io.
2. صل الآيفون بالكابل ← افتح القفل ← «الوثوق بهذا الكمبيوتر».
3. افتح Sideloadly ← اسحب `Lisancom.ipa` إليه ← اكتب Apple ID ← **Start** ← أدخل كلمة السر ورمز التحقق.
4. على الآيفون: الإعدادات ← عام ← **إدارة الأجهزة و VPN** ← اختر Apple ID ← **وثوق**.
5. فعّل **وضع المطور**: الإعدادات ← الخصوصية والأمان ← **وضع المطور** ← تشغيل ← إعادة التشغيل ← بعد الإقلاع اختر «تشغيل» وأدخل رمز القفل.
   (يظهر الخيار عادة بعد أول تثبيت عبر Sideloadly.)
6. مع Apple ID المجاني تنتهي صلاحية التطبيق بعد **7 أيام**: صل الآيفون وأعد الخطوة 3 (البيانات تبقى إن لم تحذف التطبيق).
