# العمل دون إنترنت — التصميم وخطوات التحقق

## مسار البيانات (كله على الجهاز)
ميكروفون (PCM16 16kHz مع AEC/NS/AGC) → ذاكرة فقط → Whisper في Isolate (sherpa-onnx) → فلتر الهلوسات
→ ML Kit (ar/de/en على الجهاز) → حارس الأرقام والنفي → TTS النظام.
لا يُكتب الصوت على القرص، ولا تُحفظ المحادثة. الشبكة تُستخدم فقط لتنزيل الحزم بعد موافقة المستخدم.

## أين تُخزَّن الحزم
- Whisper: `ApplicationSupport/models/<id>/{encoder.onnx,decoder.onnx,tokens.txt,installed.json}`.
  التنزيل يُكتب إلى `*.part`، ويدعم الاستكمال (HTTP Range)، ثم يُسجَّل الحجم وSHA-256.
- ML Kit: يديره نظام Google ML Kit.
- الأصوات: يديرها نظام الهاتف.

## اختبار وضع الطيران (على هاتف حقيقي)
1. مع إنترنت: نزّل كل الحزم حتى يظهر «جاهز للعمل دون إنترنت».
2. فعّل وضع الطيران، وأغلق التطبيق كليًا ثم افتحه.
3. اضغط «تحدث بالعربية» وقل: «عندي موعد عند الطبيب الساعة 3» ← يجب أن تظهر الترجمة الألمانية وتُنطق.
4. اضغط «Deutsch sprechen» وقل: „Ich bin nicht allergisch“ ← ترجمة عربية فيها نفي.
5. الترجمة النصية + دليل العبارات + النطق.
6. احذف حزمة Whisper ← يجب أن تظهر رسالة واضحة مع زر «إدارة حزم اللغات»، دون أي تعطل.
7. ابدأ تنزيلًا ثم اقطع الإنترنت ← رسالة فشل + زر «استكمال» يكمل من حيث توقف.
